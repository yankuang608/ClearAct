# Third-party dependency metadata

This source-only snapshot does not bundle node_modules, downloaded browser binaries, application images, old experiment artifacts, or third-party application source trees. Package-manager manifests and lockfiles name dependencies; they do not relicense those dependencies.

The installed packages corresponding to the lockfile were checked during preparation. Direct runtime dependencies declare MIT: @modelcontextprotocol/sdk, ajv, react, vue and ws. Playwright declares Apache-2.0. Direct build/test tooling (Changesets, tsup, tsx, React DOM, Element Plus and DefinitelyTyped packages) declares MIT; TypeScript declares Apache-2.0. Named transitive package manifests observed in that installation declared MIT, ISC, BSD-2-Clause, BSD-3-Clause or Apache-2.0. This is package metadata, not a legal opinion or proof that every future dependency/content change is covered.

Retain third-party copyright/license notices when redistributing or bundling their code. Before distributing built SDK archives or container images, review the actual bundled contents and applicable notices separately; source-only preparation does not certify those outputs. No restricted third-party application tree is included here.
